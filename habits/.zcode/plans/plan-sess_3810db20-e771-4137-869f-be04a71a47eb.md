## Goal
Make **add app → custom** work smoothly when all the user has is an app name + an App Store share link (e.g. `https://apps.apple.com/app/id1626186138`): paste the link → the app name fills itself in → the row shows the App Store icon → the link opens properly on any device.

## Changes

### 1. `js/data-normalize.js` — recognize store links (pure, offline)
- New `appStoreIdFromUrl(url)`: extracts `id(\d+)` from `apps.apple.com` / `itunes.apple.com` links (https or `itms-apps://`).
- New `appStoreSlugName(url)`: sync offline fallback name from the URL slug (`/us/app/roku-smart-home/id…` → "Roku Smart Home"); short share links have no slug → `''`.
- `normalizeUrlValue`: rewrite `itms-apps://itunes.apple.com/...` → `https://apps.apple.com/...` (https form opens the App Store app on iOS via universal links *and* works on desktop).
- `LINK_PROVIDERS` += `apps.apple.com`/`itunes.apple.com` → `app store`; `play.google.com` → `play store`.
- `APP_PROVIDER_ICONS` += `app-store: 'ti-brand-appstore'`, `play-store: 'ti-brand-google-play'` (verified present in the bundled Tabler 3.10.0 webfont).

### 2. `js/detail-view-tune.js` — smart custom-app editor
- New `fetchAppStoreName(url)`: async, per-id Map cache, ~5s AbortController timeout, GET `https://itunes.apple.com/lookup?id=N`, returns `trackName` or `''`; never throws.
- `showDetailCustomAppEditor`: focus the **URL** field first (paste-link-first flow).
- URL-field input handler: when the value is a store link, prefill the name from the slug immediately, then swap in the fetched name when it arrives — never clobbering a name the user typed (tracked via a dataset flag).
- `addCustomDetailApp` (async): if the name is empty but the URL is an App Store link, await the lookup + slug fallback before showing the "name the custom app" error — so *paste link → tap ✓* works with zero typing.
- Placeholder updates ("App Store or web link").

### 3. `index.html`
- CSP `connect-src` += `https://itunes.apple.com` (required for the lookup fetch; page + JS are SW-precached).
- Custom editor URL placeholder text.

### 4. `js/ui-kit.js` — privacy note
- Add one line to About → privacy "Other services": naming a pasted App Store link sends only the numeric app id from that link to Apple's public lookup; nothing else leaves the device. Graceful offline fallback.

### 5. `sw.js`
- Bump `CACHE` `tings-v206` → `tings-v207` (repo convention: one bump per JS/HTML change).

### 6. Tests — extend `tests/links-and-maps-test.js` (already classified `integrations once`)
- Pure normalization: the user's exact link passes through; `itms-apps://` rewritten; labels/icons for App Store + Play links; id extraction (short/slug/itms-apps forms); slug fallback name.
- Editor flow with `fetch` stubbed to a canned lookup (`trackName: 'Roku Smart Home'` for id 1626186138): paste the share link with an **empty** name → confirm → row added as `{kind:'app', label:'Roku Smart Home', value:'https://apps.apple.com/app/id1626186138'}`. Also: URL input auto-fills the name field; fetch-failure case falls back to slug name / clear error.
