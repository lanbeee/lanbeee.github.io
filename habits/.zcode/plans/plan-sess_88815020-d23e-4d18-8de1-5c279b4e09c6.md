# Refine the shared agenda display (`agenda-display.html`) for the Opera-Mini photo frame

All changes stay inside the 3 existing display files + 1 test file + `sw.js` + a one-line doc touch. No new assets, so the SW precache list is unchanged.

**Root causes found (from screenshots + code):** the "small box in top-left" is `position:fixed; inset:0` — Opera Mini's renderer doesn't support the `inset` shorthand, so the wallpaper shrinks to content size. `100svh`, `color-mix()`, `backdrop-filter`, `conic-gradient`, `mask-image`, `aspect-ratio` are also unsupported/silently dropped there (dropped `color-mix` declarations are why borders/cards look inconsistent). The triple-tap-in-900ms return gesture is impossible on a proxy browser.

## 1. `css/agenda-display.css` — rework

**Opera Mini compatibility (fallback-first, never relying on modern CSS for core layout):**
- `.agenda-wallpaper`: `top/left/right/bottom:0; width:100%; height:100%` instead of `inset:0`
- Plain `min-height:100vh` before `100svh`; plain `padding:28px 32px 34px` before the `max()/env()` padding
- A plain-color declaration line **above** every remaining `color-mix()` (buttons, `is-now`, banner, focus outline, view-only mark) so old engines keep the fallback
- Remove reliance on: `conic-gradient`, `filter:blur`, `mask-image`, `aspect-ratio` (use paired `width/height:min(64vmin,660px)`), `backdrop-filter` on cards, `text-wrap:balance`, drift animation
- Keep `clamp()/min()/grid` (they render fine on the frame per screenshot)

**True-dark theme, default dark (user choice):**
- Restructure: `:root { dark palette }` (default), `:root[data-theme="light"] { light palette }`, `@media (prefers-color-scheme: light){ :root[data-theme="system"] { light palette } }`
- Dark = near-black: `--bg:#040706`, `--bg-deep:#000`, solid cards `#0c110f`, `--line:rgba(220,235,229,.07)`, `--shadow:none`, dimmer muted text; kill the bright teal glow in dark (faint hint only)

**Cards/borders (#6):** solid card backgrounds in both themes, drop card shadows + backdrop-filter (flat like the main app), radius 18→14px (marks 16→12px) — crisper on low-res. Rewrite `is-now::before` bar with longhand offsets.

**Two-line time (#5):** `.agenda-row time` becomes a right-aligned column: `.agenda-time-start` (large, bold, `clamp(19px,1.8vw,26px)`, small inline meridiem) + `.agenda-time-end` (small, muted, ~13px, `→ 3:25 PM`). Duration-only rows show `45 min` in the start slot.

**New pieces:** header clock (`.agenda-clock`, `clamp(30px,4vw,54px)`, weight 250, tabular nums); `⋯` more button + `.agenda-menu` popover (absolute, right-aligned, solid bg, theme segmented light/dark/system + text size small/medium/large); redone night screen — pure `#000` with ultra-faint radial-gradient pattern (fallback solid black), dim sage clock `#a9b8b1`, ghost "show agenda" pill at bottom. Font scale via `--font-scale` (`.88 / 1 / 1.15`) multiplied into row/clock/title font sizes.

## 2. `agenda-display.html`

- Header right side becomes `.agenda-side` (position:relative): `<time id="agenda-clock">`, then the existing buttons row (fullscreen, hide agenda) **plus** `#agenda-more` (⋯) button, plus `#agenda-menu` (theme + text-size segmented groups, starts `hidden`)
- Night screen `#agenda-wallpaper`: keep id + `<time>/<p>` ids, replace glow/dots decorations, add `#agenda-wallpaper-show` ghost button; aria-label "Tap anywhere or swipe right to show the agenda again"

## 3. `js/agenda-display.js`

- **Clock:** one `updateDisplayClocks()` (HH:MM) + 10s interval always running; updates `#agenda-clock` and night-screen time/date
- **Appearance:** `tings_agenda_appearance_v1` = `{theme:'dark'|'light'|'system', font:'small'|'medium'|'large'}`, default `{theme:'dark', font:'medium'}` (user choice). `applyAgendaAppearance()` sets `documentElement.dataset.theme/font` + `<meta name="color-scheme">` content — **dataset/meta only, no `.style` writes** (page CSP `style-src 'self'` blocks inline styles). Applied at top-level script run (near-first-paint, before DOMContentLoaded work)
- **Menu wiring:** open/close (`hidden` + `aria-expanded`), option clicks persist+apply, outside-click/Escape closes
- **Time markup:** replace `clockRangeLabel` with pure `displayClockParts(ts,tz)` → two-span markup above
- **Gestures:** swipe left anywhere on agenda → night screen; swipe right on night → agenda (`touchstart/touchend`, passive, ≥64px horizontal, 1.75× vertical dominance, ignore touches starting on buttons/menu). **Single tap/click anywhere on night screen returns** (replaces impossible triple-tap; keep Enter/Space). Guard swallows the synthetic click right after a swipe. Drop `registerDisplayWallpaperTap`/`_displayWallpaperTaps`/dead `agenda-wallpaper-active` class; keep `tings_agenda_wallpaper_v1` persistence + refresh-on-return
