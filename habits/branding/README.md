# Tings brand source

The October 6, 2026 user-edited Affinity Photo document and 2048 px PNG preserve the original design. `tings-logo-affinity-original.svg` preserves its original hybrid export. `../icons/tings-logo.svg` is the runtime vector master: the raster mask and arrowhead patch are replaced by a single smooth arrow outline following the edited silhouette. The centered eight-point star retains its outline, with an 18% uniform enlargement. The rounded arrowhead is 20% larger, retaining both arms. Both paths are directly editable and contain no embedded bitmaps.

The simple brand mark is `../icons/tings-logo.svg`. The install-icon variant is `../icons/tings-app-icon.svg`: the same updated arrow and star geometry, with a dark blue-charcoal arrow (#26383E), golden sun (#E4A11B), a soft blue sky and a low green horizon. Its sky and ground are editable vectors, without raster textures. The landscape is reserved for PWA/Android install icons and the store icon; `tings-app-icon-twilight.svg` and `tings-app-icon-night.svg` add warm dawn/dusk and blue night palettes; in-app branding, favicon, wordmarks, splash, notification and monochrome artwork retain the simple mark. Runtime PNGs are generated from these two canonical SVGs. The original PNG and Affinity file remain unchanged as design references. After a design edit, update the runtime SVG before regeneration.

The mark is a circular return arrow surrounding a centered eight-point star (two overlapping squares), with no sparkle cutout. The center star uses warm amber-gold `#F4BC58` to also suggest the sun; the current mark also has the enlarged sun and arrowhead. Do not replace it with an earlier generated logo.

Regenerate runtime resources from the Android wrapper with `npm run brand:assets`, then `npm run sync:android`. This updates PWA favicons/install icons and Android launcher, monochrome, notification and splash images. Bump the PWA service-worker cache when replacing cached artwork. Android adaptive foregrounds are inset to keep the mark in the safe region; the landscape fills a separate background layer. The store icon has a full square sky/ground background, with no baked-in corner mask.

The branding directory is authoring material and is excluded from the Android runtime allowlist. Edit the canonical source here; `dist/` and copied Android web assets remain generated.

Android offers fixed day (default), dawn/dusk, night, or opt-in Follow daylight under Settings → Appearance → App icon. Auto uses the shared sunrise/sunset calculator for the saved home area (first saved place if no home city); without usable solar times it uses 6 AM/6 PM. Twilight lasts ±45 minutes around each boundary. A 32-day solar cache avoids GPS/network access; after it expires, fixed-clock fallback lasts until the app opens again. Cosmetic one-time WorkManager jobs may be delayed by Android. Three activity aliases target the always-enabled MainActivity; Android 13+ switches them atomically, earlier versions enable the replacement first. Android/OEM launchers may cache icons or drop a pinned alias shortcut, so this remains optional. Themed monochrome icons use the same updated silhouette. PWA/store icons stay on the day palette.
